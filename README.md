# zebrafish-toxicity-network-analysis
Multi-omics computational toxicology pipeline: PPI network analysis, scRNA-seq, molecular docking, and ML toxicity scoring for chlorpyrifos and silver nanoparticles in zebrafish.

# summary
A final-year B.Tech project that combines four computational layers to study how chlorpyrifos (a pesticide) and silver nanoparticles may disrupt biological pathways in zebrafish: protein-protein interaction networks, single-cell RNA-seq expression profiling, molecular docking, and a prototype toxicity classifier. Built to explore whether toxicity mechanisms can be screened computationally, without new animal experiments.

# skills
- Biological database mining and cleaning (CTDbase, STRING, NCBI GEO, PubChem, PDB)
- Network analysis and hub identification (Cytoscape, CytoHubba)
- Functional enrichment analysis (g:Profiler)
- scRNA-seq quality control and expression profiling (Python, pandas, Scanpy)
- Structure-based docking and interaction analysis (CB-Dock2, AutoDock Vina)
- Feature scaling, model construction and evaluation (Excel, confusion matrix)
